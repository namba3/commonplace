# サードパーティライセンスの管理

この手順は、Commonplaceのビルドツールと、生成サイトから配信する第三者資産の出典・ライセンスを追跡するためのものです。記事本文に包括ライセンスを設定する手順ではありません。

## 依存や資産を追加・更新するとき

1. 変更後の実装と `book/` の生成物を調べ、ソフトウェアがビルド専用か、ブラウザーへ配信されるかを区別します。
2. `book.toml`、Cargoの固定バージョン、ロックファイル、上流のバージョンタグや配布アセットから、実際に使うバージョンと出所を確認します。
3. 上流リポジトリの該当バージョンのライセンスファイルと、配信ファイルに含まれる著作権・ライセンス表示を確認します。READMEの説明だけでなく原文を確認し、異なるライセンス表記や追加条件があれば個別に記録します。
4. 配信資産に必要な著作権表示、ライセンス本文、原文または対応するソースへのリンクを維持します。ライセンス文書を変形せず、上流の全文を保存する場合は出所とバージョンも記録します。
5. `src/legal/third-party.md` の一覧とリンクを更新します。サイト表示に使う原文は `src/legal/licenses/` に置き、Markdownからリンクしてビルド出力に含めます。
6. READMEとこの手順の参照が有効か確認し、`mdbook build` 後に一覧ページとライセンス原文が `book/legal/` 以下に出力されたことを確認します。

## 判定と更新の注意

- ビルド専用ツールと、HTML・JavaScript・CSS・フォント・画像などの配信資産を同じ扱いにしません。配信資産にバンドルされた依存やアイコンも調べます。
- バージョンが不明なときは推測で埋めず、「上流の当該バンドル内に個別表記なし」など、確認できた範囲を記録します。
- MPLなどソースの提示条件があるライセンスでは、配信中の対象ファイルのソースを利用者が入手できる参照先も示します。改変した場合は、その変更と対象ファイルを明確にします。
- ライセンスがデュアルライセンスまたは複数ライセンスのときは選択肢を正確に記載し、単一ライセンスにまとめません。
- 著作権表示やバンドルのライセンス注記を削除しません。著作権表示の更新や依存の入れ替え後は、生成サイトの出力も再確認します。
- mdBook、`mdbook-mermaid`、配信するMermaid.jsの固定版はそれぞれ0.5.4、0.17.1、11.16.1です。更新はローカル・CI双方の準備スクリプトとこの一覧を同時に更新します。Mermaidの公式Security Advisoriesも確認し、固定した版に既知の脆弱性がないか記録します。
- `mermaid.min.js` と `mermaid-init.js` は生成資産で、Git管理せず `.gitignore` に含めます。Node.jsを導入せず、`python3 scripts/prepare-mermaid-assets.py` が `mdbook-mermaid install .` とSHA-512確認済みアーカイブから作成します。ビルド前に生成資産が必要です。実行時配信は同梱したJSで行い、CDNを参照しません。
- Pagefind 1.5.2は `package-lock.json` で固定します。CLIはビルド専用ですが、Component UI・CSS・検索ランタイム・インデックスはPagesから配信するため、上流パッケージに含まれるライセンス表示を確認し、`src/legal/third-party.md` と原文を更新します。
- 生成元ファイルに独自変更がある場合、準備スクリプトが既知の上流ハッシュと異なる内容を検出して停止します。変更をレビューするまで上書きせず、改変を保持してください。初期化コードを独自に保守する必要がある場合は、追跡可能なソースとして分離し、配信先・ライセンス・著作権表示を更新します。
- 配信バンドルの著作権・ライセンスコメントを削除・加工しません。Mermaidの版を変えたら、バンドル末尾のライセンス情報、表示された構成要素の版、上流ライセンス原文を調べ、一覧と原文を更新します。バンドルに版表示がないときは推定せず、その旨を記します。
- Commonplaceの記事・画像・独自コードのライセンスは未指定です。依存ライセンスの一覧を、サイト全体や各記事へのライセンス付与として説明しません。

## 確認コマンド

```bash
mdbook build
find book/legal -maxdepth 2 -type f -print
```

Mermaidのライセンス表示やバージョンを調べる場合は、まず `python3 scripts/prepare-mermaid-assets.py` で生成資産を準備し、実際に配信する `mermaid.min.js` のバージョンと末尾のライセンス表示をこのページと照合してください。SHA-512値は準備スクリプトで固定します。変更後は、`mdbook build` した `book/` にMermaid本体・初期化スクリプト・ライセンス原文が含まれることを確認します。ビルド成功だけではライセンス条件の確認を代替できません。
