# 編集・公開ポリシー

Commonplaceは、技術的な知識、調査結果、考察を、自分の学習や関心に沿って整理・蓄積する個人的なCommonplace Bookです。AIによる調査・執筆支援を活用し、人間による確認・校正を推奨しています。特定の企業・団体・製品の公式見解を示すサイトではありません。

## このサイトを作る理由

運営者には、AI生成の記事をZennやQiitaに投稿することに少し気が引ける感覚があります。そのため、AI利用を隠さず、人が内容を確認・編集した知見を自分のCommonplace Bookに蓄積する場として、このサイトを運営します。

## 執筆とレビュー

- AIによる下書き、構成案、要約、調査補助、文章の推敲を利用できます。
- 公開前に人が内容を読み、事実関係、論旨、読みやすさ、リンク、引用、ライセンス上の問題をレビュー・校正します。
- 技術的事実、仕様、バージョン、数値などは可能な範囲で公式文書、規格、論文、一次資料にあたります。
- 確認できていない内容は事実のように断定せず、推測・仮説・未確認事項であることを明記します。
- 実施していない実験、検証、ベンチマークを実施済みと記載しません。検証結果には条件や対象バージョンを添えます。
- AIが生成した架空の出典、引用、リンクを掲載しません。出典が主張を実際に支えていることを確認します。
- 第三者の著作物を適切な範囲で扱い、必要な帰属表示やライセンス条件を守ります。
- AI生成・AI支援を利用した場合は、記事の性質に応じて読者に分かる形で注記します。
- AI生成の文章を含む記事があります。内容の正確性・完全性・最新性は保証せず、誤りや古い情報が含まれる可能性を前提にします。

## AI利用注記

記事ごとに、AIの利用内容に応じて注記を追加できます。例:

> AIを用いて構成と文章の草案を作成し、内容を人が確認・編集しました。

この例文は事実の確認なしに貼り付けてはいけません。実際の作業と一致する場合に限り使用します。リポジトリやCIは人によるレビューの有無を自動判定せず、記事の存在やビルド成功をレビュー済みの証拠とみなしません。

## 公開後の訂正

誤りや古くなった情報が判明した場合は、根拠を確認して記事を修正します。重要な訂正は、読者が経緯を理解できるよう記事内に注記を加えることを検討します。公開済みURLは可能な限り維持します。

## 免責と権利

掲載内容は個人的な調査・学習・考察に基づき、正確性、完全性、最新性を保証しません。重要な判断や実装には公式資料などの一次情報も確認してください。記事中の企業・団体・製品との公式な関係を示すものではなく、個人の見解を所属組織などの見解として扱わないでください。

リポジトリ全体に適用するLICENSEは指定していません。Publicであることは記事、画像、コードの再配布・改変を許可することを意味しません。第三者の資料を使うときは、出典を示し、権利とライセンス条件を確認します。同梱された第三者資産には個別のライセンス表示が適用されます。
