# 参考文献と関連資料

作成日：2026-11-02 / 更新日：2026-11-02

*AIコーディング時代のデザインパターン再考 — 参考文献*

本連載の本文に記した番号と対応する出典一覧。リンク先の内容や研究の適用範囲は、それぞれの本文で説明する。


1. Erich Gamma, Richard Helm, Ralph Johnson, John Vlissides, *Design Patterns: Elements of Reusable Object-Oriented Software*, Addison-Wesley, 1994. [書誌情報](https://www.oreilly.com/library/view/design-patterns-elements/0201633612/)
2. Peter Norvig, [*Design Patterns in Dynamic Languages*](https://norvig.com/design-patterns/design-patterns.pdf), Object World, 1996（特にスライド9–10）。[紹介ページ](https://www.norvig.com/design-patterns/index.htm)
3. The Rust Programming Language, [*Closures*](https://doc.rust-lang.org/stable/book/ch13-01-closures.html), [*Pattern Syntax*](https://doc.rust-lang.org/book/ch19-03-pattern-syntax.html).
4. The Rust Reference, [*External blocks — ABI*](https://doc.rust-lang.org/reference/items/external-blocks.html)（Rust ABIの安定性に関する注意）。
5. METR, [*Measuring the Impact of Early-2025 AI on Experienced Open-Source Developer Productivity*](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/), 2025-07-10.
6. METR, [*We are Changing our Developer Productivity Experiment Design*](https://metr.org/blog/2026-02-24-uplift-update/), 2026-02-24.
7. METR, [*Task Substitution and Uplift*](https://metr.org/blog/2026-05-08-task-substitution-and-uplift/), 2026-05-08.
8. Google DORA, [*2025 State of AI-assisted Software Development Report*](https://dora.dev/research/2025/dora-report/), 2025.
9. Zhaoling Chen et al., [*LocAgent: Graph-Guided LLM Agents for Code Localization*](https://aclanthology.org/2025.acl-long.426/), *ACL 2025*, pp. 8697–8727（構造・依存関係を用いたコード位置特定の研究）。
10. Boshi Wang et al., [*Improving Code Localization with Repository Memory*](https://www.microsoft.com/en-us/research/publication/improving-code-localization-with-repository-memory/), *ICLR 2026*（変更履歴を利用したコード位置特定の研究）。
11. Birgitta Böckeler, [*Harness engineering for coding agent users*](https://martinfowler.com/articles/harness-engineering.html), Martin Fowler, 2026-04-02.
12. Donald E. Knuth, [*Structured Programming with go to Statements*](https://gwern.net/doc/cs/algorithm/1974-knuth.pdf), *ACM Computing Surveys*, 6(4), pp. 261–301, 1974（特にp. 268）。
13. Gene M. Amdahl, [*Validity of the Single Processor Approach to Achieving Large Scale Computing Capabilities*](https://doi.org/10.1145/1465482.1465560), *AFIPS Spring Joint Computer Conference*, pp. 483–485, 1967. 補足解説：Mark D. Hill, Michael R. Marty, [*Amdahl’s Law in the Multicore Era*](https://research.cs.wisc.edu/multifacet/papers/ieeecomputer08_amdahl_multicore.pdf), *IEEE Computer*, 41(7), 2008。
14. Jeffrey Jian Ma et al., [*SWE-fficiency: Can Language Models Optimize Real-World Repositories on Real Workloads?*](https://proceedings.mlr.press/v306/ma26l.html), *Proceedings of ICML 2026*, PMLR 306, 2026（報告値はこの採録版に準拠）。[評価方法と再現用コード](https://github.com/swefficiency/swefficiency).
15. Zhi Chen et al., [*Are Performance-Optimization Benchmarks Reliably Measuring Coding Agents?*](https://arxiv.org/abs/2607.01211), arXiv:2607.01211, 2026（査読済み論文としてではなくプレプリントとして参照）。
