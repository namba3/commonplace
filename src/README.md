## AIの利用

調査、構成、文章生成、編集にAIを活用しており、AIが生成した文章を含む記事があります。人による確認・校正を推奨する方針ですが、記事ごとに確認範囲は異なります。誤りや古い情報が含まれる可能性があるため、重要な判断では公式資料などの一次情報もご確認ください。内容は必要に応じて訂正・更新します。
