# 第9回：何を実証すればよいのか――評価設計と今後の展望
作成日：2026-11-03 / 更新日：2026-11-03

> **この回の問い：** 最終回では、観察された事実、公開モデルでの実証、統合に関する未検証の仮説を並べて整理する。計算コストと品質の比較、介入実験、反証条件を明確にし、「反復が推論能力を生む」という主張を検証可能な形にする。

## 1. 本稿の主張を証拠の強さで整理する

| 主張 | 現状の評価 | 理由 |
| --- | --- | --- |
| 隣接層に重みの類似性が見られる | **観察された事実** | DOCSなど、対象モデルでの実測がある |
| Residual Streamは情報を引き継ぎながら更新される | **構造・分析に基づく事実** | 残差接続と回路分析が支持する |
| 重み共有は有効なモデル構成になり得る | **公開実装・実験で支持** | Universal Transformer、Huginn、Ouroなど |
| 固定点への接近は計算省略の手掛かりになる | **条件付きで公開実験がある** | HuangらPart II。ただし正答性の証拠ではない |
| より多い反復は常により良い回答を生む | **支持されない** | 品質は反復回数に対して単調とは限らない |
| 内部反復は常に段階的な推論である | **未証明** | 因果的な検証が必要 |
| テキストCoT以外の中間表現が有用になり得る | **課題依存で実証が進む** | Coconut、Mirageなど |
| 将来トークンの教師信号を反復状態へ与えられる | **公開実験で支持** | LoopMTP。ただし小規模・特定条件 |
| 反復途中の状態をDraft生成に使える | **公開実装・実験で支持** | LoopSpec、LoopAhead。検証条件が重要 |
| Masked DiffusionでもDepth Recurrenceが有効になり得る | **公開実験で支持** | LoopMDM。反復配置・ノイズ水準に依存 |
| 既存Denseモデルのループ化や少ない学習トークンでの学習が有効 | **プレプリントで条件付き支持** | 特定の学習レシピ・比較条件での報告。本稿では独立追試の有無を確認していない |
| MTP＋Block Diffusion＋Recurrent Coreの3方式の統合が一般に最適 | **未検証の仮説** | 同一予算の交互作用実験が必要 |
| 商用の非公開モデルが特定の反復構造を採用している | **個別の根拠が必要** | 性能や応答挙動からの推測だけでは特定できない |

OpenAIやAnthropicの個別モデルについて、関係者報道や振る舞いの観察を手掛かりに構造を推測することはできる。しかし、内部の反復回数・重み共有範囲・停止規則が公式に公開されない限り、**特定の構造を採用済みと断定しない**。本稿の議論は公開論文に基づくアーキテクチャ上の可能性が中心である。公開論文の成果も、それぞれの評価タスク・規模・学習条件の範囲に限定して読む必要がある。

学習コストに関しては、Ouroの約7.7兆トークンという報告だけで、ループ型モデルに必要な規模を代表させない。2026年のプレプリント[Closing the Loop](https://arxiv.org/abs/2610.00673)は、310Bトークンの学習レシピと、Qwen3-1.7B-Baseを継続学習でループ化する方法を提示し、論文内の条件を揃えたDenseベースラインとの比較を報告した。これは実用的な導入経路の可能性を広げる一方、著者らの実験条件に依存する結果として読む必要がある。

## 2. 設計仮説を検証するための実験

層間類似性とRecurrent-Depthを、単なる類推ではなく実験可能な仮説として結びつけたい。

| 実験 | 測定対象 | 確かめたいこと |
| --- | --- | --- |
| Weight Similarity | 隣接する重み行列の分布・類似度 | どの層を共有できそうか |
| Functional Similarity | 同じ入力状態に対するブロックの応答 | 数値的な重みの類似と関数の類似を分離 |
| Residual / Update Analysis | 状態と更新量のノルム・方向・部分空間 | 小さな差分が何を変えているか |
| Cross-layer State Matching | 学習時の自然な状態分布の整合・変換 | 別の層の重みを再利用するときの分布ずれ |
| Layer Replacement | 層を隣接層の重みで置換 | 共有にどこまで耐えられるか |
| Shared Weight + Adapter | 共有重みと低ランク差分 | 圧縮率と精度のトレードオフ |
| Loop Count Sweep | 反復回数と正答率・校正・停止挙動 | いつ計算を増やす価値があるか |
| Timestep Conditioning Ablation | 深度なし、絶対深度、正規化深度＋刻み幅、Loop/Branch/AdaLN Gate | 反復条件のどの情報が有効か |
| History-State Injection Ablation | 初期状態注入、履歴差分、両者、履歴窓サイズ | 過去軌跡の寄与と追加キャッシュの費用 |
| Prefix vs Rescaled Budget | 途中停止、最初から再スケジュール、途中予算変更 | 状態再利用と軌跡の一致性 |
| Depth-vs-CoT Budget | 同じFLOPsで内部反復と追加CoTを比較 | どの課題にどの追加計算が効くか |
| MTP Supervision Ablation | NTPのみ、通常MTP、LoopMTP、TOP、深度条件付けとの併用 | 未来距離と反復段階の整合性 |
| Draft Acceptance / Distribution | 浅い反復で提案し深い反復で検証 | 高速化とTarget分布保存を分離 |
| Depth-vs-Denoising Budget | 同一計算量で\\(R\\)と\\(S\\)を交換し、両時刻の条件付けを分離 | 反復が代替的か相補的か |
| Block Boundary Intervention | 過去ブロックの誤りや制約を導入 | 大域的一貫性・修正可能性 |
| Activation Patching | 中間状態への介入 | どの中間状態が回答に因果的に効くか |
| Latent Chain Deletion | 中間ステップの削除・置換 | 推論がそのチェーンを本当に使っているか |
| Multimodal Intervention | 画像の位置・形状・関係の変更 | 反復状態が視覚情報に依存して更新されるか |

比較は少なくとも、**①同じ学習計算量、②同じ常駐パラメータ数、③同じ推論FLOPs、④同じ実測レイテンシ**という複数の軸で別々に行いたい。さらに、DenseとMoEでは常駐パラメータ・活性化パラメータ・実際に実行したFLOPsを区別する必要がある。加えて、同じTokenizer・学習データ分布・学習トークン数・出力長・バッチ条件を可能な範囲で揃え、**複数の乱数Seedと信頼区間**を使うことで、反復の効果と偶然の差を分ける必要がある。さらに、生成品質だけでなく、元のTarget分布の保存を主張する手法には**分布一致の確認**を独立した検証項目として設ける。これらを同時に揃えようとすると比較対象が不自然になる場合もあるため、**どの予算を等しくした比較なのか**を明示する方が有益だ。

たとえば、同じ計算予算で「独立層を増やす」「共有Coreの反復を増やす」「テキストCoTを増やす」の3方式を比較する。さらに共有Coreについて、固定反復・適応反復・軽量Adapter付きを切り分ければ、どの変更に改善が由来するか検証しやすい。

また、異なる層に同じ人工状態を入力する比較は、学習時に経験していない分布へ入る可能性がある。そのため、同一状態での応答比較と、自然な入力分布での層置換・介入の両方を用いることが望ましい。

### 最小限の再現性チェック

同じ「最大高速化率」を掲げる研究でも、測定条件が変われば順位は入れ替わる。論文の結果を比較するため、最低限、**モデルのチェックポイントと改訂版、Tokenizer、入力長と出力長、精度設定、GPU、バッチサイズ、KVキャッシュ方式、Samplerの停止条件**を固定・記録したい。加えて、**同じ品質のモデルをより速くしたのか、別の品質のモデルをより小さな重みで得たのか**を目的別に分ける。

| 目的 | 優先する比較基準 | あわせて記録する指標 |
| --- | --- | --- |
| 重み共有の効率 | 学習予算、常駐パラメータ数 | 推論FLOPs、精度、メモリ |
| 推論時間の改善 | 同一Target分布または同品質 | TTFT、ITL、スループット、受理率 |
| 潜在計算の有用性 | 同一推論FLOPsまたは同一レイテンシ | 正答率、校正、介入後の変化 |
| 拡散型生成の品質 | 同一サンプラー・生成長・計算予算 | NLL推定方法、修正回数、境界整合性 |

## 3. 3方式の統合を検証する：段階的アブレーションと交互作用

単一の統合モデルだけを作って精度が上がっても、どの技術が寄与したのかは分からない。**学習時の目的関数を変える効果**と**推論時のスケジューリングを変える効果**をさらに区別する必要がある。少なくとも、次の順番で比較することを提案する。

1. **単独効果**：通常Transformer、Recurrent-Depth、MTP補助学習、Block Diffusionを、学習予算を明示して比較する。
2. **2方式の相互作用**：Recurrent-Depth＋MTP、Recurrent-Depth＋Denoising、MTP Draft＋Denoisingを個別に検証する。
3. **3方式の統合**：2方式モデルと比較し、初めて統合の付加価値を問う。
4. **制御の学習**：固定\\(R,S,K,n_b\\)と、適応的な配分を同じ費用で比較する。
5. **因果介入**：Draft、途中反復状態、ブロックの未確定状態を個別に置換・削除し、機構が本当に利用されているか調べる。

**最小限の検証実験**としては、同じTokenizer、データ、モデル幅、予算を明示したうえで、まずMasked Diffusionモデルを\\(R=1\\)と\\(R>1\\)で比較し、それぞれについてDenoisingステップ数\\(S\\)を変える2×2以上の実験が考えられる。さらにMTP補助学習の有無を加えると、\\(R\\)と\\(S\\)の交互作用がMTPによって変わるかを検証できる。**総学習FLOPsと総推論FLOPsを無視して単純に\\(R\\)や\\(S\\)を増やす比較は避ける。**

たとえば、まず \\(R\in\{1,4\}\\)、\\(S\in\{4,16\}\\) の4条件を実行するとする（**数値は実験設計の例で、論文の最適値ではない**）。これにMTP補助学習の有無を加えれば8条件になる。ただし条件ごとにFLOPsが異なるため、これは**効果の分解を優先した実験**である。別途、同一レイテンシに収まる \\(R,S\\) の候補集合を探索し、費用対効果のPareto Frontierを比較する。

この実験では、最終スコアの主効果だけでなく、次の差分も重要になる。ただし**固定した反復数同士の単純な比較**と、**総推論FLOPsを一定にした配分の比較**は異なる。前者は交互作用を解析しやすいが、条件ごとに計算予算が違う。後者は公平なコスト比較になるが、他のモデル設定や内部反復の割り当ても変える必要がある。

\\[
I_{R,S} = [Q(R_2,S_2)-Q(R_1,S_2)]
-[Q(R_2,S_1)-Q(R_1,S_1)]
\\]

\\(Q\\)は値が大きいほど品質が高い指標を、同じ条件で測った値とする。\\(I_{R,S}\\)が正なら、この比較範囲では\\(S\\)を増やすことが深さの追加効果を強めたことを示す。負なら代替性を示唆する。ただし、これは**比較条件内の交互作用**であって、モデル一般の因果的な法則ではない。固定予算での比較では\\(R,S\\)の組を再設計する必要がある。**同一FLOPs上の複数構成を比較するだけでは、この2因子を独立に操作した交互作用と同じ量を推定できない**。

生成分布を評価する際も注意が要る。自己回帰モデルの通常のTeacher-forcing NLL、Masked Diffusionの変分下界・NLL推定、生成サンプルに基づくGenerative Perplexityを、**同じ尺度として無条件に横並びにしない**。推定器、系列長、データ分布、サンプリング設定を揃える必要がある。

指標は、NLL・Generative Perplexity・タスク正答率だけでなく、**同一FLOPsでの品質、同一レイテンシでの品質、KVを含む最大メモリ、受理率、修正率、ブロック境界をまたぐ整合性、長文生成でのエラー累積**を含めたい。

また、同じタスク正答率でも、**初回トークンまでの待ち時間（TTFT）**、**出力トークン間の遅延（ITL）**、長文での品質劣化、**入力長に対する計算量の傾き**は異なり得る。実用的な「効率」は、単一の最大高速化倍率でなく、レイテンシ・スループット・メモリ・精度のトレードオフとして示すべきである。

もし、同じ推論予算では浅いCoreと長いDenoisingの組合せが常に深いCoreを上回るなら、両者の反復は強く代替的かもしれない。逆に、同じ費用で2方式の統合が各単独方式を安定して上回るなら、反復の相補性を示す有力な根拠になる。

## 4. 残る未解決問題と、仮説を弱める結果

Recurrent-Depthが有力な設計方向であるとしても、次の問題は残る。特に、**失敗を説明できない仮説は強い仮説とは言えない**。

- **深さと幅の最適配分：** 同じFLOPsなら、大きなモデルを浅く実行する方がよいのか、小さなモデルを深く反復する方がよいのか。
- **適応停止の信頼性：** 出力が安定したことと、正解に到達したことをどう区別するか。
- **深度条件と計算進捗のずれ：** 反復の時刻を伝えるだけで、必要な計算・停止時点を正しく選べるか。
- **履歴と推論時メモリ：** 状態差分の保存・再利用コストを含めて、条件付けの利益が残るか。
- **予算変更と軌跡整合：** 途中から反復回数を延長しても、最初から長い予算を使った結果と一致するか。
- **共有による制約：** 独立層が持つ機能分化を、共有Coreと小さな補正でどこまで再現できるか。
- **潜在状態の解釈可能性：** モデルが実際に計算した因果的な過程を、どの程度検証できるか。
- **マルチモーダルな状態操作：** 図形変換や物体追跡のような操作が、中間状態に安定して表現されるか。
- **実装効率：** KVキャッシュ、逐次依存、可変反復数を含む実運用で、十分な効率が得られるか。
- **先読みの限界：** 遠い将来位置の正解トークンを学習させることで、かえって中間表現が劣化しないか。
- **ブロック境界と確率分布：** 拡散の柔軟性とキャッシュ効率を維持しながら、大域的修正と分布の整合性を両立できるか。
- **3方式の統合の実利：** 追加モジュール・制御の複雑さが、実測レイテンシや品質の利得を上回らないか。

たとえば、同じ推論FLOPsで通常の独立層モデルが一貫して上回る、反復の途中に適切な介入を加えても答えや分布が変わらない、十分な追加学習後にも反復回数の増加が利用されない、といった結果が広い条件で再現されれば、**「深さ方向の共有反復が一般に優れた計算単位である」という強い主張は修正すべき**だろう。

## 5. まとめ：生成・予測・内部計算を、分けて設計する

本稿の出発点は、**隣接層の重みの類似性**と、**Residual Streamが深さ方向に保持・更新されること**だった。これらは重み共有と反復状態更新を試す動機になる。ただし、層間の類似性からRecurrent-Depthが最適と結論することはできない。

Looped Transformer / Recurrent-Depth Transformerは、**重みを共有したまま論理的な深さを増やす**という明確なアーキテクチャ上の選択肢を提示した。さらに深度条件付けとHistory-State Injectionは、**同じ重みでも現在の計算段階と過去の軌跡に応じて更新規則を変調できる**ことを示している。しかし、反復が多ければ必ず良いわけでもなく、潜在状態に段階的推論が実装されているとも限らない。

CoTは中間推論をテキストとして外部化する方法であり、深さ方向の再帰そのものではない。VLMでは、この出力形式の制約が特に目立つ。一方、**MTPは将来位置の情報を先読み・学習する**、**Block Diffusionは複数トークンの候補を反復的に修正する**という別の軸を与える。

重要なのは、これらを単に組み合わせて計算量を増やすのではなく、次の設計問題を分離することだ。

> **どの情報を状態として保持するか。どの演算器を共有するか。どの将来位置まで予測するか。どの出力位置を同時に修正するか。何回計算して、どの条件で確定するか。**

2026年のLoopMTP、LoopSpec、LoopAhead、LoopMDM、Diffusion Forcing Samplerなどは、これらの設計軸が実際に交わり始めていることを示す。特に、**学習時の教師信号、生成アルゴリズム、実行スケジュール**は、同じモデルを使っていても別の設計判断である。すなわち、**学習目標としての先読み、推論時の先読み、生成候補の修正**は別々に評価する必要がある。ただし、**MTP＋Block Diffusion＋Recurrent-Depthの完全統合が有利だという結論はまだない**。分布保存、計算予算、学習安定性、因果的な中間状態の利用を切り分ける実験が必要である。

一方、共有Coreが引き起こす逐次依存、Denoisingの再計算、MTP Draftの棄却率が組み合わさると、各単独方式より遅くなる可能性もある。3方式の統合がうまく働くかを判断するには、「何がどこで再利用され、どの処理が省略されたか」を実測する必要がある。

モデルの「思考時間」をCoTの長さや反復回数だけで測るのではなく、**どの状態を、現在深度と過去の履歴を含むどのような条件で、どれだけ効率的に更新・確定できるか**という視点が、今後の推論・生成アーキテクチャを理解する鍵になるかもしれない。

---

**この回の結論：** 推論・先読み・候補の修正・出力への確定は、原理的に異なる操作として扱える。次の課題は、それぞれの計算をどこで何回実行すべきかを、公平な予算条件と因果的な実験で明らかにすることである。
