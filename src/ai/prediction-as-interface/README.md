# 予測というインターフェイスから見るAIの内部世界

作成日：2026-10-14 / 更新日：2026-10-14

**副題：単純に見える出力の背後にある、表現学習・マルチモーダル統合・世界モデル**

> **本シリーズの問い**：LLMは次トークンを、拡散・Flow Matching系モデルはノイズや速度を予測する。しかし、その比較的簡潔な出力形式の背後には、豊かな内部表現、複雑な生成過程、多様なモダリティを統合するTransformer、行動に応じて未来を予測する世界モデルがあり得る。これらを、どこまで共通の構図で理解できるだろうか。
>
> **中心的な見方**：次トークンのロジットや画像潜在の速度推定は、内部で獲得された計算能力を**次の処理へ渡すためのインターフェイス**と捉えられる。この見方は、出力の形式と内部計算の豊かさを区別するための**分析上の比喩**であり、内部に完全な「思考」が実体として保存されているという主張ではない。さらに、読み出し、サンプリング・積分、外部への表示や作用は別の境界として扱う。

本シリーズは、確立した数学的関係、研究で観測された結果、著者の解釈・仮説を区別する。人間の思考と言語化の類似は**機能的なアナロジー**として論じ、神経科学上の同一性やAIの主観的経験を意味しない。技術的事実の対象時点は**2026年10月14日**。

## 前提と読み方

数式に馴染みがない場合は、第1章・第4章・第6章・第9章を、まず本文と図を中心に読むと全体像をつかみやすい。式は説明を追ううえで必要になったときに参照できる。Transformerの残差経路や表現学習の数学を確認したい場合は、Commonplaceの[「Deep Learningのパラダイムシフト」](../deep-learning-paradigm-shifts/)も参照。

本稿はモデルの能力を過小評価する「ただの次トークン予測」と、予測だけで高度な能力が必ず生まれるとする過大評価の、**どちらも避ける**ことを目指す。

本シリーズを通じて、特に次の三点を区別する。

- **出力の形式と内部計算**：一度に確定するトークンが一つでも、文脈全体に依存する複雑な計算が必要になり得る。逆に、出力形式だけから特定の知識や推論能力の存在を証明することもできない。
- **表現の共有と世界への適合**：同じTransformerで画像・文章などを扱えることは、両者の意味が整合したことや、介入に応じた世界の変化を正しく予測できることとは違う。
- **生成の反復と外界への作用**：次トークン生成、画像潜在の数値積分、ツール・ロボットを使った再観測は別のループである。学習による重み更新も、さらに別のループに位置する。

## 先に示す結論：四つの「接続」を区別する

本シリーズの「インターフェイス」は、単一の端子の名前ではなく、役割の異なる**境界を順に接続する**という分析上の視点である。

| 境界 | 入力と出力 | 本稿での代表例 |
| --- | --- | --- |
| **読み出し** | Hidden State → 予測値 | 次トークンのロジット、画像潜在の速度 |
| **生成手順** | 予測値 → 次の生成状態 | トークン選択、Flow Matchingのソルバー |
| **モダリティ変換** | 画像・音声・文章 → 共通計算／専用出力 | 視覚Encoder、共有Transformer、音声／画像Decoder |
| **環境との接続** | 観測 → 行動 → 新しい観測 | GUIエージェント、ロボット、世界モデルを使う計画 |

これらの境界は実装では枝分かれし、必ず上から順に通る単一パイプラインとは限らない。この区別により、**豊かな内部表現があること、複数のモダリティを扱えること、行動の結果を予測できること**を同一の能力とみなさずに済む。第1〜3章で予測と表現の関係、第4〜5章でマルチモーダル統合の設計原理、第6〜7章で世界モデルと行動、第8〜9章で証拠と限界を扱う。
