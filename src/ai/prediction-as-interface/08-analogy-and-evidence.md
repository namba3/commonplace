# 第8章：人間との類似、証拠、検証方法

ここまでの枠組みは、人間がさまざまなことを考えながら言語化する姿と、どこか似ている。**出力された一文は、内部処理の全容ではない。** だが、この類似を強調しすぎれば、Deep Learningと脳科学の違いを消してしまう。

## 8.1 思考と言語化：役割のアナロジー

人間は、必ずしも思考のすべてを逐語的に発話していない。視覚イメージ、運動感覚、記憶、概念的な関係など、言語以外の形式が認知活動に関わる。そこから一部を言葉や身振りとして外へ表現する。

LLMにも、多層のHidden Stateを計算してからトークンへ読み出すという構造がある。**出力インターフェイスだけを見ても内部計算の全体は分からない**という点では、機能的に比較できる。

| 比較軸 | 人間 | 典型的なLLM・AIシステム |
| --- | --- | --- |
| 内部状態 | 神経活動、知覚、記憶などが関わる | Hidden State、文脈、外部メモリ等 |
| 読み出し | 発話、文章、運動など | トークン、音声生成器、画像生成器、行動ヘッド等 |
| 時間的更新 | 継続的な身体・環境との相互作用 | 層内計算、逐次生成、環境との反復など |
| 学習・可塑性 | 生涯の学習、複雑な適応 | 事前学習、事後学習、オンライン更新を行う構成など |
| 不明な点 | 認知の機構に未解明点が多い | 内部表現・能力の一般的な成立条件に未解明点が多い |

ここで**「人間の言語化は内部思考の出力ヘッドに相当する」**というのは、説明のための比喩だ。人間の言語は思考を**表現するだけでなく、思考を組み立てたり方向づけたりすることもある**。同様に、LLMが書いた途中式は、後続トークンの文脈となり計算に役立つ場合がある。言語と計算の関係を一方向に限定しない方が正確である。

## 8.2 「内部に表現がある」の証拠の強さ

研究論文に「世界表現が見つかった」と書かれていても、観測方法は一つではない。

| 方法 | 支持しやすい主張 | それだけでは言えないこと |
| --- | --- | --- |
| **Probe** | 特定情報がHidden Stateから復号可能 | 予測時にその情報を使っている |
| **Activation介入** | 操作した内部成分が出力に因果的影響を与えた可能性 | 特定の意味概念が完全に独立して存在する |
| **予測性能** | テスト条件下で次状態や観測を予測できる | あらゆる介入下で正しい世界モデルを持つ |
| **計画の成功** | 予測が行動選択に実用的だった | 訓練外の環境でも信頼できる |
| **外部形式検証** | 形式化された命題と証明の整合性を機械検査できる | 自然言語の元問題との一致や現実の安全性 |

介入も万能ではない。ある活性を変更して出力が変化したとしても、それだけで介入対象を「人間が名づけた一つの概念」と同定できるとは限らない。対照介入、局所性、複数の文脈にわたる再現性を調べる必要がある。

モデルの内部表現は座標変換による自由度を持ち、同一の入出力を実現する内部実装が複数あり得る。**一つの読み出し器や可視化だけで、内部に唯一の意味構造が存在することを証明したとは言えない**。

## 8.3 実験案A：小さな系列モデルに状態表現が生じるか

ゲームや有限状態機械で、現在の状態 \\(s_t\\) を明示的な教師ラベルとして与えず、行動列の次の記号だけを予測する小型Transformerを学習する。

1. 隠れ状態から \\(s_t\\) をProbeで復元できるか確認する。
2. 短い履歴しか参照しないベースラインや頻度ベースラインと比較する。
3. 特定の状態情報に対する介入と、無関係な介入を比較する。
4. 未見の長さや初期状態でも予測できるかを測る。

**結果は未実施の実験案**である。Probeの精度と介入の成功は別に報告すべきだ。

## 8.4 実験案B：Unified Transformerが何を本当に共有しているか

人工的な二モダリティ系列を作る。例えば、同じ有限状態機械の状態を**記号列**と**小さな画像**の両方から観測できるようにする。次状態予測や対応付けを学習させる。

比較するのは次の条件である。

- 専用Encoder＋共有Transformerと、完全に独立した二モデル。
- 共通幅のトークンを連結するだけの条件と、両モダリティの対応学習を加える条件。
- Cross-Attention型とJoint Self-Attention型。
- データ漏洩を防いだ正しいMaskと、意図的に不適切なMaskを用いた診断条件。

訓練データ量、総パラメータ数、計算量はできる限り統制し、「共通Hidden幅だから意味も共有された」という誤認を防ぐ。学習した対応を**未知の組合せ**でも利用できるか確認する。

## 8.5 実験案C：動画の続きを当てることと、行動の未来を当てること

小さな2D物理シミュレータで、物体位置・速度と行動を記録する。次の画像だけを予測するモデルと、行動\\(a_t\\)を条件として未来状態を予測するモデルを比較する。

- 訓練で見た行動分布内の予測誤差。
- 訓練であまり見ない行動での誤差。
- 数ステップ先の誤差累積。
- 世界モデルを使った計画の成功率。
- 見た目だけもっともらしい失敗ケース。

この比較により、**見た目の映像生成性能**と、**介入に対する信頼できる予測**の違いを具体化できる。実験結果は作っていない。

## 8.6 実験案D：同じ場面から異なる出力を評価する

第4章の**赤い球を右へ押す**場面を使い、入力に同じ場面の記述・画像を用意して、出力ごとに評価基準を変える。

1. **認識**：VLMが球の位置・周辺物体との関係を正しく説明できるか。
2. **生成**：条件付き画像生成モデルが、指定した移動先や形状を適切に描けるか。
3. **未来予測**：行動条件付きモデルが、力・摩擦などの条件変更に応じた結果を予測できるか。
4. **外部ループ**：行動を実行するエージェントが、新しい観測を取り込むことで制御を改善できるか。

これは同一モデルの性能順位付けではなく、**同じ場面に対する異なる入出力契約**の検証案である。条件、データ量、推論計算量、評価方法を記録しなければ、差をモデルのアーキテクチャだけに帰属できない。すべて**未実施の実験案**である。

## 8.7 「インターフェイス」という見方から、何を検証できるか

「出力形式だけでは内部能力を評価できない」というのは、主に**概念を整理する観点**であり、そのままでは反証可能な科学仮説ではない。一方、「モデルが状態を追跡している」「モダリティ間で意味を共有した」「行動の効果を予測できる」は実験で支持・否定し得る。そこで、本稿の解釈から生まれる具体的な主張を、次のように検証する。

- **状態表現の因果的な寄与**：推定された表現を選択的に消去・撹乱し、予測精度の変化を測る。適切な対照介入と比べ、精度低下が再現するか、別の特徴で補われるかも確認する。精度低下はその条件下での寄与を支持するが、表現の唯一性や一般的な必要性を単独で示すものではない。
- **モダリティ間の実質的な共有**：見た目や語彙だけを変えた未見の組合せに、学習した対応が利用できるか。
- **行動条件付きの妥当性**：未知の操作の結果を、オープンループ動画予測より正確に予測できるか。
- **実行系の寄与**：同一のモデル重みで、ソルバー・検証器・ツールの有無だけを変えたとき成果がどれだけ違うか。

このような**対照群・介入・外部評価**がなければ、個別の能力についての断定はできない。一方、これらの実験結果がどうであれ、「出力形式と内部計算を区別する」という説明上の区分そのものを、単一の実験の成否で証明・反証したことにはならない。

## 8.8 記事全体で避けたい三つの飛躍

**第一に、出力形式の簡潔さから内部計算の簡潔さを推論しない。** 第二に、豊かな内部表現の存在から人間と同じ理解・意識を推論しない。第三に、マルチモーダルの統合から行動条件付きの正しい世界モデルが成立したと推論しない。

これらを分ければ、Deep Learningの能力を過小評価する必要も、根拠なく神秘化する必要もなくなる。
